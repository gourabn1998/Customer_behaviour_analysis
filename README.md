# Customer Behaviour Analysis

A data analysis project that explores customer purchasing behaviour, product performance, shipping preferences, and subscription patterns using **Python, MySQL, and Power BI**.

The project follows a pure practical analytics workflow: prepare and transform the customer's data in Python, load the prepared data into MySQL, answer important business questions with SQL, and present selected findings in an interactive Power BI dashboard.

## Project Overview

The analysis uses a customer shopping behaviour dataset. The working table referenced by the SQL scripts is `customer_analysis`, stored in the MySQL database `customer_behaviour`.

The project examines:

- Revenue by gender and product category
- Average purchase amount and customer ratings
- Discount usage and purchase behaviour
- Subscription status and spending
- Customer segments based on previous purchases
- Product popularity within categories
- Revenue across age groups
- Shipping preferences

## Project Workflow

1. **Inspect the data in Python**  
   Load the CSV file into a Pandas DataFrame and inspect sample rows, summary statistics, data types, and missing values.

2. **Clean and prepare the data**  
   Fill missing review ratings using the mean review rating within each product category. Standardise column names, create age groups, convert purchase frequency labels into day values, remove the `promo_code_used` column after checking it against `discount_applied`, and rename the purchase amount column.

3. **Load the prepared data into MySQL**  
   Connect to the local MySQL database with SQLAlchemy and load the DataFrame into the `customer_analysis` table.

4. **Perform SQL analysis**  
   Run queries to answer ten customer and business questions using grouping, filtering, subqueries, conditional aggregation, CTEs, and window functions.

5. **Build the Power BI dashboard**  
   Present key customer and revenue measures with charts and slicers for exploring the data.

## Python Data Preparation

The notebook `DataAnalysis-.ipynb` contains the preparation workflow.

The notebook includes:

- Reading the customer shopping behaviour CSV file with Pandas
- Inspecting the data with `head()`, `describe()`, `info()`, and missing-value checks
- Grouping records by category
- Filling missing `Review Rating` values with the mean rating for the relevant category
- Converting column names to lowercase and replacing spaces with underscores
- Creating an `age_category` field using quartiles (`pd.qcut`)
- Creating `purchase_frequency_days` by mapping purchase frequency labels to day values
- Comparing `promo_code_used` with `discount_applied` before dropping `promo_code_used`
- Renaming `purchase_amount_(usd)` to `purchase_amount`
- Loading the prepared DataFrame into MySQL

### Age groups

The notebook creates four age groups using `pd.qcut` with the labels `young`, `adults`, `middle_aged`, and `senior`.

### Purchase frequency conversion

The notebook maps the frequency labels to approximate day values:

|---|---:|

| Bi-Weekly | 14 |

## SQL Business Analysis

The SQL file `customer_behavior_sql_queries.sql` contains ten business questions and their queries.

| # | Business question | SQL concepts used |
|---:|---|---|
| 1 | What is the total revenue generated by male and female customers? | `GROUP BY`, `SUM()` |
| 2 | Which customers used a discount but spent more than the average purchase amount? | `WHERE`, subquery, `AVG()` |
| 3 | Which five products have the highest average review ratings? | `GROUP BY`, `AVG()`, `ORDER BY`, `LIMIT` |
| 4 | How does the average purchase amount compare between Express and Standard shipping? | Filtering, `GROUP BY`, `AVG()` |
| 5 | How do subscriber and non-subscriber counts, average spending, and total revenue compare? | `COUNT()`, `AVG()`, `SUM()`, `GROUP BY` |
| 6 | Which five products have the highest percentage of purchases with discounts? | `CASE`, conditional aggregation, percentage calculation |
| 7 | How many customers fall into New, Returning, and Loyal segments based on previous purchases? | CTE, `CASE`, `GROUP BY` |
| 8 | What are the top three most purchased products within each category? | `ROW_NUMBER()`, window function, subquery |
| 9 | Among customers with more than five previous purchases, how many are subscribers and non-subscribers? | `WHERE`, `GROUP BY`, `COUNT()` |
| 10 | What is the revenue contribution of each age group? | `GROUP BY`, `SUM()`, `ORDER BY` |

### Customer segmentation logic

The SQL script uses the following rules:

- **New:** 1 previous purchase
- **Returning:** 2 to 15 previous purchases
- **Loyal:** More than 15 previous purchases

These are the exact segment boundaries used in the query.

## How to Reproduce the Analysis

### 1. Prepare the Python environment

Install the required packages:

```bash
pip install pandas sqlalchemy mysql-connector-python jupyter
```

### 2. Prepare the dataset

Place the customer shopping behaviour CSV file in a known location and update the CSV path in the notebook to match your computer.

### 3. Prepare MySQL

Create the database:

```sql
CREATE DATABASE customer_behaviour;
```

Open the notebook and update the MySQL connection settings for your own local environment. Do not commit database passwords or other secrets to GitHub.

### 4. Run the notebook

Run `DataAnalysis-.ipynb` from top to bottom. The notebook prepares the data and writes it to the `customer_analysis` table.

The notebook currently uses `if_exists='replace'`, which replaces the destination table when it runs. Use this only when that behaviour is intended.

### 5. Run the SQL queries

Open `customer_behavior_sql_queries.sql` in MySQL Workbench or another MySQL client. Run the statements against the `customer_behaviour` database.

### 6. Open the Power BI report

Open `customer_behaviour analysis.pbix` in Power BI Desktop. If the report asks for a data source, configure it to use your own MySQL connection and refresh the data.
